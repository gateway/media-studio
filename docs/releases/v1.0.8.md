# Media Studio v1.0.8

- Jobs correctly reports the responding web server as running, including production Next.js processes named next-server and systems where process discovery is unavailable.
- Stale failed launchd entries no longer make a responding manual web server appear failed. Restart controls remain limited to launchd-managed services.
- The macOS guide documents how to persistently retire failing legacy login agents while retaining their configuration and all Studio data.

No schema, provider, or Python environment changes.
