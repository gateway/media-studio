# Media Studio v1.0.7

## macOS desktop launcher

- Onboarding offers a branded Media Studio.app Desktop icon. Existing users can add it with `npm run desktop:install:mac`.
- Double-clicking starts the existing production launcher, shows progress in Terminal, and opens Studio in the browser. Ctrl+C or Stop Media Studio.command stops the app.
- The icon remembers Node/tool paths from installation. Reinstall it after moving the checkout or replacing Node.
- Launching again after startup reopens the running instance, including automatically selected ports.

## Graph node spacing

- Loaded workflows, expanded fields, and arriving previews automatically separate overlapping nodes.
- Spacing uses measured dimensions, including collapsed nodes, and waits until dragging or resizing ends.
- Already separated nodes retain their positions; queued corrections do not overwrite newer canvas state.

The private shared Python environment from v1.0.6 is unchanged. Existing configuration, databases, and media remain in place. Normal launchers run in production mode; `npm run dev` remains the contributor development path.
