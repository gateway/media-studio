# Media Studio v1.0.6

## Isolated Python onboarding

- Onboarding downloads private Python 3.11 without changing system Python, PATH, or shell profiles.
- KIE API and Media Studio API use one shared virtual environment.
- Setup checks package compatibility, backend/provider imports, and the model list before reporting success.
- Interrupted package setup can be retried. Existing incompatible environments are preserved with migration guidance.

Existing installations keep their configuration, databases, and media. If onboarding
asks you to move an old `.venv` aside, stop Studio first and leave `.env` and data folders in place.
