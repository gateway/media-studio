# Media Studio v1.0.4

## Assistant model choices

AI Settings → Media Assistant now offers separate text-to-image and image-to-image defaults from the eligible KIE model catalog. Explicit requests take priority, existing presets keep their selected models, and unresolved choices ask for clarification. Newly available models become selectable after a catalog refresh; defaults do not silently switch to the newest model.

The conversation provider remains separate from the image model used for generation. Full Media Assistant actions currently require Codex Local.

## Graph layout and setup

- Assistant proposals correct node spacing using rendered dimensions, including later content and preview growth. Manual node movement ends that automatic correction.
- Groups keep their members and padded enclosure during automatic resizing. Dragging a node out still removes it from the group.
- The Assistant entry stays visible when setup is incomplete. It explains what is missing, links to Setup and AI Settings, and offers Check again. Operational actions remain gated by feature opt-in and Codex readiness.
- Model node headers avoid repeating their default title; renamed nodes retain their model identity. Info popovers have an opaque background.

## Preset saving

Verified Assistant preset saves attach the approved image as a thumbnail when none was explicitly chosen. If thumbnail storage fails, the successful preset save is preserved and the UI shows the remaining action.

## Updating

Update Media Studio and its shared KIE dependency, then restart the API and web app. The additive database migration stores optional Assistant image defaults; existing workflows, media and provider settings are preserved. Media Assistant remains opt-in through `NEXT_PUBLIC_MEDIA_STUDIO_ASSISTANT_DEBUG=1` at API startup and web build/startup. Install and sign in to Codex on the machine running Media Studio; Media Studio starts the runtime automatically.

Local verification and release-gate evidence are recorded separately from these public release notes. No additional media generation is needed to verify the layout or setup changes.
