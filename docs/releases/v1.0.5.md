# Media Studio v1.0.5

## Media Assistant communication and recovery

- Clearer replies and completion cards explain what was prepared, applied, saved, or left to do.
- Returning to a workflow or reloading restores saved replies, active progress, and Stop controls.
- Failed requests retain their text and recovery options, including guidance for missing provider configuration.
- Replies preserve creative details, numbering, line breaks, and literal snippets.
- Requests, progress, and actions stay with their original workflow when you switch tabs.

## Updated product guide

The README now puts installation near the top, documents the current image, video, audio, and optional text/vision model categories, and explains presets, Prompt Recipes, Graph Studio, and Media Assistant. Maintainer versioning instructions have been removed.

Media Assistant and Graph Studio remain experimental. Applying graph changes and starting generation remain separate actions.
