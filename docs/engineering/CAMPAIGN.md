## Task Eligibility

A task is campaign eligible only when it is marked campaign eligible in [TASKS.md](TASKS.md), has no paid/external side effect, lists allowed files, has deterministic verification, and can stop cleanly. Existing dirty files must be preserved and scoped diffs reviewed before edits.

## Hard Stop Conditions

- A test fails for an unclear or unrelated reason.
- Required files overlap user changes that cannot be isolated safely.
- A route, API shape, schema, migration, auth, billing, pricing, dependency, lockfile, or production config change appears necessary.
- A new public recipe port is proposed instead of using existing declared roles without explicit approval.
- Any workflow other than `graphwf_4fd06f50c493` would be mutated.
- Browser verification is replaced with a different automation surface.
- A provider image/video submission is about to occur without action-time approval.
- Seedance is enabled or would submit.
- A sixth Phase 11 paid run is proposed, or any paid run falls outside the sequential storyboard proof.
