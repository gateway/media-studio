# Desktop icon

`media-studio.icns` is the macOS rendition of `apps/web/app/icon.svg`.
It contains 16, 32, 128, 256 and 512 pixel icons at 1x and 2x resolution.
It was rendered with the web workspace's Sharp dependency and packaged with
macOS `iconutil -c icns`. Users do not need image tools during onboarding.
